## 0. Architecture decisions

| # | Decision | Choice | Tag |
|---|---|---|---|
| A1 | Where the theme lives | `theme/` at the repo root (standard OS 2.0 folders inside). Next.js app stays untouched at the root as the reference. All theme paths below are relative to `theme/`. Theme check: `npx -y @shopify/cli@latest theme check --path theme`. | [default] |
| A2 | JS | One vanilla custom element per component in `assets/<name>.js`, `defer`-loaded by the section that needs it. No framework, no bundler, no jQuery. framer-motion behaviour is ported to CSS transitions/keyframes + small rAF/IntersectionObserver code. Springs are approximated with CSS `linear()` easings (values listed per task). | [default] |
| A3 | CSS | `assets/tokens.css` (custom properties) + `assets/base.css` (reset/globals) loaded globally; one `assets/section-<name>.css` per section, loaded by that section; shared components in `assets/component-<name>.css`. Class naming: `<component>__<element>`; state via the same `data-*` attributes the React source uses (`data-open`, `data-on`, `data-shown`, `data-active`, `data-state`, `data-unavailable`, …). | [default] |
| A4 | Test hooks | Every `data-section` / `data-*` hook in audit §7.20 + §5.8a is kept on the equivalent element so `scripts/test-store.mjs` and the compare tool can target both sites. | [default] |
| A5 | Cart | Shopify cart replaces the localStorage bag. `assets/cart.js` wraps `/cart/add.js`, `/cart/change.js`, `/cart.js` + Section Rendering API (re-renders `cart-drawer`). Document events keep the source names: `khuwabb-bag-open`, `khuwabb-bag-change`. | [default] |
| A6 | Money | Snippet `price.liquid` + JS `Khuwabb.formatMoney(cents)` output `settings.currency_prefix` (`Rs.`) + grouped amount with no decimals → `Rs.2,500`. Never use raw `\| money` in sections (store money format is unknown from here). | [default] |
| A7 | Product cut-outs | **Product media + alt-text convention** (see §3.2). One media image per colour per view; alt = `<Color value> \| <view>`; views `front`, `side`, `back`, `piece-top`, `piece-bottom`. Snippet `product-cutouts.liquid` parses it. Display alt is generated by the theme (`<title> in <colour>, <view> view`), so the stored alt is only a key. | [Shad] |
| A8 | Custom product data | Product metafields in namespace `custom` (see §3.3) + product type = category + collections. | [Shad] |
| A9 | Fixed decorative images | Theme assets: logo, 6 intro cut-outs, New-in header image, empty-bag image. Editorial photos (collections rail, wear-the-dream, 4 look photos) are `image_picker` settings with a **theme-asset fallback** when blank, so pages render before anything is uploaded to Files. | [default] |
| A10 | Fonts | Ship the 4 woff2 files as theme assets; `@font-face` in `snippets/head-fonts.liquid` with `font-display: swap` and `preload` for the 4 faces; metric-matched fallback faces (`size-adjust` / `ascent-override` / `descent-override` / `line-gap-override`) copied from the Next build's generated CSS (Batch 0 prep task extracts them). | [default] |
| A11 | Store data setup | A script in `tools/store-setup/` (Admin GraphQL API, run by Shad locally with an Admin API token) uploads cut-outs with the alt convention, sets product types + metafields, creates collections, menus, Files and URL redirects. Written in Stage A, **not run** here. | [Shad] |
| A12 | Ownership of templates and section groups | `templates/**/*.json` and `sections/*-group.json` are **Opus-owned** (like the other shared files): agents propose entries, Opus merges. Add to the CLAUDE.md shared list on approval. | [default] |
| A13 | Compare tool command | `tools/compare/` gets its own `package.json`. Root `package.json`: existing `compare` (Framer-vs-Next) renamed `compare:framer`; `compare` → `node tools/compare/run.mjs`. Reference = Next.js (`http://localhost:3000` or `https://khuwabb-leftovers.vercel.app`), theme = `http://127.0.0.1:9292`. | [default] |

### 1.1 Cross-component contracts (fixed now so parallel tasks agree)
- **Section roots**: `data-section="<name>"` (names from audit §5.8a / §7.20) goes on the section's own root element inside Shopify's `shopify-section-*` wrapper. Fonts use Next's generated family names (`clashDisplay`, `satoshi`) via `var(--font-display)` / `var(--font-body)` — never hardcode family names.
- **Intro state**: `html[data-intro-playing]` (see §2.3); `html.js` is set before first paint. `scoop-intro.js` must **remove** `data-intro-playing` from `<html>` when the overlay is removed (the compare tool waits on it). The overlay keeps the `data-intro` attribute.
- **Seeded randomness**: reels/shuffle code calls `window.reelsRandom()` at call time (never caches `Math.random`); define `window.reelsRandom ||= Math.random`.
- **Bag button** (rendered by header): `<button type="button" class="bag-button" data-bag-button aria-label="{{ 'bag.button_label' | t: count: cart.item_count }}"><span>Bag</span><span class="bag-button__badge" data-bag-count>{{ cart.item_count }}</span></button>`. Click → `document.dispatchEvent(new CustomEvent('khuwabb-bag-open'))`. `cart-drawer.js` updates `[data-bag-count]`, the aria-label, and toggles `data-bump` for 600 ms when the count rises. Styles for `.bag-button` live in `section-header.css`.
- **Cart API** (`assets/cart.js`, global `window.Khuwabb.cart`): `add(items: [{id, quantity}]) → Promise<cart>`, `change(key, quantity)`, `get()`. After every mutation it fetches `?sections=cart-drawer`, swaps the drawer HTML and dispatches `khuwabb-bag-change` with `detail.cart`. `add()` also dispatches `khuwabb-bag-open`. Errors (422 etc.) reject with `{status, message}`.
- **Product JSON** (`snippets/product-json.liquid`, render with `product:`): `{id, handle, title, url, price, type, tint, categoryLine, colours: [{name, views: {front, side, back, pieceTop, pieceBottom} each {src, srcset, width, height} or null}], sizes: [...], variants: {"<Color> / <Size>": {id, available}}}`. Used by hero-reels, look chooser, product form.
- **Appear**: `data-appear="rise|lift"` on an element → `appear.js` toggles `data-shown` when it enters/leaves the viewport (thresholds .3 / .2); CSS in `base.css` (reduced motion → always shown).
- **Money**: `{% render 'price', price: x %}` / `Khuwabb.formatMoney(cents)`.
- **Global JS config** (`snippets/head-config.liquid`): `window.Khuwabb = {routes: {cart, cart_add, cart_change, root}, currencyPrefix, checkoutEnabled, strings: {…from locales}}`.

### 3.2 Product media convention (A7) [Shad]
- One image per **colour × view**, uploaded from `public/products/<slug>/<folder>/<view>.webp` (full-size file, not the `-NNNh` variants; Shopify's CDN makes sizes).
- **Alt text = `<Color value exactly as in Shopify> | <view>`**, e.g. `White with red stripes | front`, `Black | piece-top`.
- Folder → Colour value map comes from `scripts/build-khuwabb-data.mjs` (e.g. `off-white` → `White`).
- Each variant's `featured_media` = its colour's `front` image (so Shopify checkout/admin show the right photo).
- `product-cutouts.liquid` builds `{colour: {view: media}}` by splitting alt on ` | `; media with other alts are ignored (so existing studio photos can stay). Fallback when a colour has no `front`: `product.featured_media`.
